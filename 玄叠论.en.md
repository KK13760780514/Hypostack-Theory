### 1.1 Core Presuppositions

Any theory needs to presuppose certain premises. Newtonian mechanics presupposes "gravity exists," special relativity presupposes "the speed of light is constant." This theory likewise needs to presuppose certain premises. These presuppositions are not proven truths but starting points for theoretical deduction. This is the most fundamental logical starting point of the entire theory. We cannot explain "why there isn't only one structure"-any attempt to explain this necessarily presupposes at least an explainer and an explained object, thereby already presupposing co-existence. Asking "why co-existence" equals asking "why relations exist rather than non-existence." This is the common boundary of any relational ontology, not a unique defect of this theory.

Co-existence is listed as "Presupposition Zero" rather than an "axiom" because: axioms typically expect to be proven or at least widely accepted; whereas co-existence is a logical starting point that cannot be proven. Labeling it "Presupposition Zero" is to honestly tell everyone: this is our starting point. We do not pretend it can be derived from any more fundamental principle.

There is no unified timeline covering the entire universe. Structures evolve according to causal order: if the input of operation B depends on the output of operation A, then A precedes B. This "precedence" does not presuppose a time axis, only causal dependency.

The speed of light c is the upper limit of information transmission rate in all local causal sequences. c is not a constraint externally imposed on local sequences but a property of local sequences themselves-the limit value of any signal's rate when transmitting from one structure to another. ### 3.2 Ten-Layer Chain

**Layer 0: Prerequisites.** The structure must possess F (foldability), S (sentience), E (driving force) to enter evolution.

**Layer 1: Perturbation.** External or internal factors that break the information symmetric state.

**Layer 2: Breaking.** The structure selects one path from multiple possible evolutionary paths under perturbation, with the selection criterion being the path most favorable for eliminating the current dominant difference.

**Layer 3: HypoStack Operation.** Four operation types-zero operation (maintain status quo, Δ_coord=0), welding (heterogeneous HypoStack, Δ_coord>0.05), printing (homogeneous HypoStack, Δ_coord≤0.05), forced HypoStack (external high-energy structure intervention). Operation thresholds are empirical parameters based on the 0-10 scoring system's structural properties. Any researcher may propose alternative threshold schemes through protocol improvement proposals. If alternative thresholds perform better empirically, the original thresholds are replaced.

**Layer 4: Hysteresis Locking (Solidification).** Operation results are temporarily fixed. What is irreversible is the causal consequence, not the information state itself. Once causal consequences are produced, they cannot be retracted; but information states can be modified by new operations. An apology does not equal restoring the original state, rolling back code does not mean nothing happened, active dissolution is not going back in time.

**Layer 5: Perturbation Response.** The environment's continuous action on the fixed structure, producing no new HypoStack unless accumulation reaches a threshold triggering new breaking.

**Layer 6: Structural Result.** The structure forms a stable form.

**Layer 7: Stable Selection.** The frugal are more likely to be retained at this layer. The costly are eliminated. What we see as "rewards" is merely survivor bias.

**Layer 8: Recursive Echo.** Successfully retained structures influence the next round of information authoring. When one structure's Layer 8 influences another structure's Layer 0, two independent causal sequences have interwoven.

**Layer 9: De-HypoStack (Dissolution).** The structure dissipates, with four paths: exhaustion dissolution (driving force drops below threshold), shattering dissolution (external perturbation exceeds rigidity limit), active dissolution (high self-referential depth structure actively exits), fusion dissolution (completely welded into a larger structure).

### 3.3 Irreversibility

The direction of evolution is irreversible. This is not an additional assumption but a causal consequence of Layer 4. What is irreversible is the causal consequence-consequences that have occurred cannot be "undone," only overwritten by new operations. Irreversibility is not a property bestowed by physical time but a fundamental property of causality: once a consequence occurs, it cannot be "revoked."

### Universal Experimental Design Template

Any predictive argument validation experiment for any discipline must follow this template:

**1. Prediction statement**: Derive a specific prediction for that discipline based on S = ∫ E dN.

**2. Experimental design**: Set up a difference to be eliminated, design two paths to eliminate the difference-Path A (lower consumption per step), Path B (higher consumption per step). Both paths have the same endpoint-eliminating the same difference. Ensure conditions other than path consumption are as identical as possible.

**3. Computable version**: Use the discrete form S = Σ (E_i × ΔN_i). If every step's E for Path A is less than or equal to Path B's, and the number of steps is fewer or equal, then Path A's S is necessarily smaller.

**4. Statistical threshold**: p < 0.01 (t-test between groups or equivalent non-parametric test).

**5. Falsification condition**: If the system statistically significantly selects the path with larger S, then this specific prediction is falsified. Note: falsification of a single prediction does not equal falsification of HypoStack Theory-it only means the prediction failed under specific conditions, requiring revision of auxiliary hypotheses or re-examination.

**6. Preregistration system**: The experimental plan must be submitted to a community public registry before experiment execution. Preregistration content includes four immutable declarations: E measurement paradigm, N calculation method, S calculation method, statistical threshold for significant deviation. Modification after experiment is prohibited. Non-compliant reports will not be accepted.

**Supplementary note: operational definition of 'selection' (2026-08-01).** S = ∫ E dN is a "selection record" (the frugal survive, the costly fade); "selection" in this template refers to testable retention/dominance outcomes, not active will. Testing can take two forms:

- **Ordering test**: Compute S for two imposed paths separately, test whether the smaller-S path dominates in retention, frequency, or convergence (all current open-validation claims use this form);
- **Choice/switching test**: Let the system face candidate paths, or change path costs mid-course, test whether it shifts/switches to the smaller-S path (stronger form, design draft at [predictions-operationalization.md](open-validation/predictions-operationalization.md) P-ECO-002).
