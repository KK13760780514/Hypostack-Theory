# 九维坐标降维检验方案提案框架（Presupposition 3 / Dimensionality-Reduction）

> 状态：**提案框架**（proposal framework，待社区认领与数据就绪后实算）
> 关联：[玄叠论.md](../玄叠论.md) 1.1 节预设三（九维完备 / F·Φ·N 强耦合）、1.4 节"无法消除多维度量衡的量纲冲突"、2.3 节距离度量、附录E（度规与测地线）、[math-foundations.md](math-foundations.md) Q5。
> 本框架不完成降维证明，只把检验路径形式化、列出所需数据与验收标准，供社区在数据就绪后执行。

## 1. 问题现状

预设三断言：结构的所有可观测属性可由九维坐标 `(F, S, E, N, R, Φ, K, Ξ, λ)` 完全描述，不存在第十种不可约属性。理论已诚实声明：

- `F / Φ / N` 三者存在强耦合，若可互相推导，九维坐标可降维为七维或更少；
- 降维检验路径已写入预设三："通过主成分分析（PCA）计算方差贡献率，若两个维度的累计贡献率超过阈值，可被合并"；
- 九个维度量纲不同，当前用马氏距离 / 余弦相似度缓解，**完整流形度规未完成**（附录E 悬赏）。

**当前缺口**：上述降维检验尚无实算数据——九维坐标目前主要靠人工逐案标注，缺乏一个足够大、跨结构类型的坐标数据集来跑 PCA / 流形学习。

## 2. 目标

在数据就绪后，检验预设三的降维分支是否成立，并回答两个子问题：

1. **可合并性**：九维坐标中是否存在可由其余维度（线性或非线性）重构的维度？（即是否存在可降维的冗余）
2. **完备性边界**：现有九维是否能覆盖观测到的结构属性变异，还是存在显著的"残差方向"提示第十种不可约属性？

## 3. 检验路径（候选路线）

### 路线 R1：PCA 方差贡献率（线性，预设三指定）

- **方法**：对标准化后的九维坐标矩阵做 PCA，计算各主成分方差贡献率。
- **判据（候选阈值，可调）**：若某两个原始维度可由前 k 个主成分以累计贡献率 ≥ 95% 重构，则判定这两维可合并。
- **局限**：仅捕捉线性相关；`F/Φ/N` 的耦合若为非线性则可能被低估。

### 路线 R2：相关 / 冗余分析（成对维度）

- **方法**：计算九维间的相关矩阵（Pearson / Spearman），识别 |ρ| 高的维度对。
- **判据（候选）**：|ρ| ≥ 0.9 的维度对作为"候选可合并对"，进入路线 R3 的非线性复核。
- **局限**：线性相关阈值，且高相关不等于可互相推导。

### 路线 R3：非线性重构 / 流形学习

- **方法**：用自编码器 / UMAP / 核 PCA 估计内在维度，检验是否存在远低于 9 的内在维数。
- **判据（候选）**：内在维度估计值 ≤ 7 且重构误差 < 5%，则支持"可降维"。
- **局限**：依赖样本量与模型选择；结果需与 R1/R2 交叉验证。

### 路线 R4（反例驱动）：第十维挑战

- **方法**：社区成员提出一个候选"第十种不可约属性"，并尝试用九维的函数 `f(F,S,E,N,R,Φ,K,Ξ,λ)` 重构它。
- **判据**：若存在可行重构函数，则该属性非不可约；若多方尝试均无法重构，则预设三需修正。
- **地位**：这是预设三自带证伪条件的操作化，与 R1–R3 互补。
- **认领入口**：[issue #15](https://github.com/KK13760780514/Hypostack-Theory/issues/15)。

### R4 首批候选分析（2026-08-02，提出者分析）

以下对 3 个候选"第十维"进行初步可约性分析。每个候选取自不同学科领域，覆盖物理、数学、信息论方向。

#### 候选 T-1：时间不可逆性（Time irreversibility, τ）

- **定义**：结构演化过程的方向性--熵增方向、因果关系不可逆转。
- **重构尝试**：S = ∫E dN 是路径积分，沿时间正向积累，本身已隐含时间方向；Ξ（噪声）与热力学涨落相关，是不可逆性的微观来源。
- **结论**：**可约**。时间不可逆性已隐含在 S 的路径积分定义中（S 只能沿时间正向增长，反向路径的 S 无定义或不同）。无需引入独立维度。

#### 候选 T-2：对称群类型（Symmetry group type, Σ）

- **定义**：结构具有的对称群类型（如 Z₂ 空间反演、U(1) 相位、SU(2) 自旋、SU(3) 色荷）。
- **重构尝试**：Φ（耦合）描述维度间相互作用强度，但仅给出耦合的"强度"而非"对称性类型"。两个 Φ 值相同的结构可能具有不同的对称群（如 Z₂ vs U(1)）。K（冗余）描述备份路径数量，也不编码对称群信息。λ（标度）描述尺度不变性，与分形对称性相关但不等同于对称群类型。
- **部分反驳**：可论证对称性是耦合结构（Φ）的特定模式--例如 Z₂ 对称要求 Φ 的特定排列。但即使如此，对称群的"类型"（离散 vs 连续、Abel vs 非 Abel）不可仅由 Φ 的数值推导，需要额外的群结构信息。
- **结论**：**部分不可约**。对称性的"程度"可由 Φ 近似捕获，但对称群的"类型"（离散/连续、Abel/非 Abel）不可约。这是一个有潜力的第十维候选，但需要更严格的数学论证（如：构造两个九维坐标完全相同但对称群不同的结构）。

#### 候选 T-3：拓扑不变量（Topological invariant, G）

- **定义**：结构的全局拓扑性质，如亏格（genus）、Betti 数、连通分量数、纽结类型。
- **重构尝试**：Φ（耦合）描述局部连接强度，K（冗余）描述备份路径，但全局拓扑不变量是"拓扑等价类"下的不变量，不可由局部性质推导。两个局部耦合结构（Φ, K）完全相同但全局拓扑不同的网络存在（例如：环形网络与树形网络可以有相同的平均度和冗余度，但亏格不同）。
- **反驳尝试**：可论证拓扑是全部九维坐标的"涌现"性质。但即使给定全部九维坐标的数值，也无法唯一确定拓扑不变量--因为九维坐标是"属性"而非"连接矩阵"。
- **结论**：**不可约（初步）**。拓扑不变量是一个有效的第十维候选。当前九维坐标描述的是结构的标量属性，不包含结构连接矩阵的完整信息，因此无法重构全局拓扑。若理论要覆盖拓扑性质，可能需要增加拓扑维度或将 Φ 扩展为矩阵（而非标量）。

### R4 小结

| 候选 | 可约性 | 结论 | 是否挑战预设三 |
|------|--------|------|---------------|
| T-1 时间不可逆性 | 可约 | S 路径积分已隐含 | 否 |
| T-2 对称群类型 | 部分不可约 | 群类型不可由 Φ 标量推导 | **潜在挑战**（需更严格论证） |
| T-3 拓扑不变量 | 不可约（初步） | 九维标量属性不含连接矩阵信息 | **有效挑战** |

**诚实声明**：以上分析为初步的逻辑/构造性论证，不是严格数学证明。T-2 和 T-3 的"不可约"结论需要通过构造反例（两个九维坐标完全相同但属性不同的结构）来严格验证。欢迎社区提出更多候选或对以上分析提出反驳。

## 4. 数据需求

| 需求 | 说明 | 现状 |
|------|------|------|
| 样本量 | PCA / 流形学习建议 ≥ 100 个结构样本（九维齐全）；理想 ≥ 500 | **不足**（当前主要为逐案人工标注） |
| 覆盖度 | 跨结构类型（物理 / 生物 / 认知 / 社会 / 人工系统），避免单一类型导致伪降维 | 不足 |
| 标注规范 | 每样本需附测量范式、度量者标识、XRS 映射（见 2.5 节范式声明） | 部分具备 |
| 量纲处理 | 先标准化 / 无量纲化（与附录E 度规、math-foundations Q5 联动） | 方案待统一 |

**结论**：降维实算（R1–R3）**当前卡在数据不足**。短期内可执行的是：完善标注规范、积累数据集；R4（第十维挑战）不依赖大数据，**现在即可开放**。

## 5. 验收标准

- [ ] 数据集达标（样本量、覆盖度、标注规范均满足第 4 节）
- [ ] 至少执行 R1（PCA）与 R2（相关分析），结果公开
- [ ] 若 R1/R2 提示可降维，用 R3 非线性方法复核
- [ ] 结论二选一：① 报告可合并维度及重构误差；② 报告未发现可降维冗余（此时九维维持）
- [ ] 任何降维结论须同步评估对距离度量（2.3 节）与复制保真度 Δ_coord（2.4 节）的影响
- [ ] 负面结果（无法降维 / 数据不足无法判定）同样记录入账

## 6. 与现有框架的关系

- **预设三**：本框架是其降维检验路径的操作化；
- **附录E 度规**：降维（若成立）会改变流形维数，需与度规推导联动（见 [math-foundations.md](math-foundations.md) §4）；
- **Q5 量纲**：降维前的标准化方案与 Q5 共用；
- **证据入账**：数值结果按 [submission-schema.json](submission-schema.json) 以 exploratory 入账；结论性提案按 DEC 流程评审。

## 7. 优先级与贡献方式

| 路线 | 难度 | 数据依赖 | 优先级 |
|------|------|----------|--------|
| R4 第十维挑战 | 低-中 | 无（逻辑/构造） | **高（现在可做）** |
| 标注规范完善 | 低 | 无 | 高 |

**贡献方式**：任何路线的提案、反例、数据集、数值实验均可开 issue（可用 [task-proposal 模板](../.github/ISSUE_TEMPLATE/task-proposal.md)）；数值类按开放验证流程入账，提案类按 DEC 评审。**反例同样欢迎**——构造出一个无法被九维重构的"第十维"，是对预设三的直接挑战，属于重要贡献。
