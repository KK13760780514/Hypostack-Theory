# 数学基础开放课题备忘录（Math Foundations）

> 状态：**开放课题**（open problem），需要数学 / 数学物理背景的社区贡献。
> 关联：[玄叠论.md](../玄叠论.md) 1.4 节"数学基础欠账"、附录E（度规与测地线推导，悬赏完整推导）、开放决策清单 [open-decisions.md](open-decisions.md)。
> 本备忘录不假装完成了证明，只把问题形式化、列出候选路线与验收标准，供社区认领。

## 1. 问题现状

核心公式 `S = ∫ E dN` 目前是离散和 `S = Σ(E_i × ΔN_i)` 的记号缩写。理论文档（1.4 节）已诚实声明：其测度论定义、连续极限的可积性与存在性**尚未建立**。当前所有验证实验均使用离散可计算版本，因此已有证据**不依赖于**连续版本的严格化——但理论的数学地位悬而未决。

## 2. 问题的形式化表述

给定：

- 一条演化路径：有限或可数个步骤的序列 `{N_i}`（叠层数递增）；
- 每步的驱动强度 `E_i`（可测量量，如活化能、损失水平、归一化温度差）；
- 步长 `ΔN_i = N_{i+1} - N_i`。

离散定义：`S_path = Σ_i E_i × ΔN_i`。

要建立连续定义 `S = ∫ E dN`，需要回答：

1. **积分对象**：`E` 与 `N` 是什么空间上的什么对象？（`E` 是 `N` 的函数 `E(N)`？还是路径 `N(τ)` 上的泛函 `E[N(·)]`？）
2. **测度**：`dN` 对应什么测度？（计数测度的连续类比、勒贝格-斯蒂尔杰斯测度、还是路径空间上的测度？）
3. **收敛**：离散和 `Σ(E_i ΔN_i)` 在网格细化下的极限是否存在？是否与路径无关（黎曼性质）？
4. **最小化**：极小化 `∫ E dN` 的问题是否适定（解存在、唯一或至少非空）？

## 3. 核心开放子问题

### Q1：`E` 的依赖结构

- **问题**：`E` 在物理类比中对应"拉格朗日量密度"，其依赖的是构型（位置/速度），而非独立变量本身。`E_i` 在现有实验中依赖什么？（CHEM：活化能常数；ADAM：loss 水平 `loss_i`；PHASE：归一化温度差 `|T_i - T_c|/T_c`。）
- **候选路线**：将 `E` 形式化为路径 `N(t)`（`t` 为某种外部参数）上的泛函 `E = E(N(t), dN/dt, t)`，使 `S` 成为作用量泛函 `∫_0^T E(...) dN`，再研究其欧拉-拉格朗日方程是否与"第2层破缺选择"对应。
- **社区入口**：先从 ADAM（`E = loss` 已知解析形式）建立最简可算模型。

### Q2：测度与积分类型

- **问题**：`dN` 若对应计数测度（步数离散），连续极限下的测度是什么？
- **候选路线**：
  - 勒贝格-斯蒂尔杰斯积分 `S = ∫ E dN`（`N` 视为单调不减函数，`dN` 为其斯蒂尔杰斯测度）——当 `N` 绝对连续时退化为 `∫ E N'(t) dt`；
  - 路径积分（维纳测度 / 布朗桥类比）——但需先回答 Q1 的依赖结构；
  - 格点极限（lattice limit）：对离散和求细粒化极限，检验收敛性（可先数值验证）。
- **社区入口**：对 CHEM/PHASE 的参考实现数据做"步数细分收敛"数值检验，作为最小可复现的第一步。

### Q3：离散-连续一致性

- **问题**：参考实现全部使用离散定义。连续定义与离散定义何时一致？
- **候选验收标准**：对给定路径族，存在网格细化序列使 `Σ(E_i ΔN_i)` 收敛；收敛值与路径的"自然参数化"无关（至少稳定）。
- **数值验证**：phase_transition.py 的温度步数从 20 细分到 200/2000，观察 `S_A` 是否收敛——这是**当前可立即执行**的最低成本验证，不需要理论推导。复核召集：[issue #14](https://github.com/KK13760780514/Hypostack-Theory/issues/14)。

**初步数值证据（2026-08-01，[phase_convergence.py](reference-implementation/phase_convergence.py)）**：固定总 MC sweeps=4000，细分温度步数 n∈{2,5,10,20,50,100,200,400}，12 种子均值（种子 0-11，2026-08-01 强化版）：

| n_steps | 均值 S | 标准差 | 相对 n=20 |
|---|---|---|---|
| 2 | 126741 | 585 | 2.59 |
| 5 | 69433 | 485 | 1.42 |
| 10 | 55447 | 493 | 1.13 |
| 20 | 48903 | 281 | 1.00 |
| 50 | 45254 | 433 | 0.925 |
| 100 | 43670 | 332 | 0.893 |
| 200 | 43293 | 344 | 0.885 |
| 400 | 43132 | 312 | 0.882 |

- 网格细化下 S 单调下降并趋稳：200->400 相对变化仅 **-0.37%**（<1%），且随网格加密持续收窄（100->200 为 -0.86%、200->400 为 -0.37%），显示**连续极限有存在迹象**。
- 各网格点种子间标准差 <1.3%（如 n=400：43132±312），跨种子稳定性良好。
- n=20 复现值 48903 与账本均值 48903 一致（<0.1%），脚本可靠性确认。

**收敛速率分析（2026-08-02）**：相邻网格加倍时相对变化呈递减趋势：

| 网格加倍 | 相对变化 | 趋势 |
|---|---|---|
| 50 -> 100 | -3.51% | |
| 100 -> 200 | -0.86% | |
| 200 -> 400 | -0.37% | |

相对变化随网格加密大致减半，符合 **O(1/n) 收敛速率**（Riemann 和的典型收敛阶）。外推 n=800 预期相对变化约 -0.19%，n=1600 约 -0.10%--渐近极限存在但收敛缓慢。

**路径排序稳定性（2026-08-02）**：phase_convergence.py 的 n_steps 值对应不同冷却协议（n 越大 = 温度步越细 = 冷却越慢）。S 随 n 单调递减，意味着"慢冷 S 更小"的排序在**所有网格点**（n=2 到 400）均成立：

| n_steps | S | 含义 |
|---|---|---|
| 2 | 126741 | 粗网格（快冷） |
| 5 | 69433 | 中冷（= phase_transition.py 路径 B） |
| 20 | 48903 | 慢冷（= phase_transition.py 路径 A） |
| 400 | 43132 | 极慢冷（渐近区） |

路径排序 S_慢 < S_中 < S_快 在全部 8 个网格点上稳定成立，且随网格加密排序间距不反转。**这对理论的预言验证至关重要**：即使 S 的绝对值依赖网格，路径排序（可证伪预测的核心）是网格无关的。

- **诚实解读**：S 的绝对值仍依赖网格（n=20 与 n=400 相差约 12%），"连续极限存在"是数值迹象而非严格证明；但路径排序的网格无关性意味着**当前 support 结论（S_A < S_C）不依赖网格选择**。Q1/Q2 的理论形式化（测度类型、E 依赖结构）仍待推进。**欢迎外部复核者用不同实现复跑并扩大种子数。**

### Q4：最小化问题的适定性

- **问题**：`min_path ∫ E dN` 的解是否存在、是否唯一？"系统选择 S 最小路径"的数学表述是什么？
- **候选路线**：若 `E` 与路径参数无关（CHEM 情形），`S = E_eff`（常数），最小化退化为求 `min E_eff`——这是平凡情况；真正有趣的是 `E` 依赖路径历史的泛函情形（ADAM、PHASE），此时需研究变分问题的解。
- **注意**：已有教训（ISSUE-001）--"系统选择路径"不能靠人为构造路径来验证；数学形式化同样不能预设极小化者的存在。

### Q1/Q2 形式化提案（2026-08-02，提出者分析）

#### Lebesgue-Stieltjes 框架

**关键观察**：N（叠层数/步数）在物理上是一个**单调不减函数** N(t)（步数只能增加，不能减少）。这意味着 dN 是一个合法的 Lebesgue-Stieltjes 测度，S = ∫ E dN 是一个良定义的 Lebesgue-Stieltjes 积分。

- **离散情形**（当前所有参考实现）：N(t) 是阶梯函数，dN = Σ_i δ(t - t_i) ΔN_i，积分退化为 S = Σ_i E_i ΔN_i。
- **连续情形**：若 N(t) 绝对连续，dN = N'(t) dt，积分变为 S = ∫ E(t) N'(t) dt。
- **混合情形**：N(t) 可同时有连续部分和跳跃部分（如化学反应中连续温度变化 + 离散反应事件），Lebesgue-Stieltjes 积分自然处理。

**结论**：Q2（测度类型）有明确答案--dN 是 Lebesgue-Stieltjes 测度，S = ∫ E dN 是 Lebesgue-Stieltjes 积分。这是标准数学框架，不需要新数学。Q3 的收敛性问题转化为：E(t) 和 N(t) 是否具有足够正则性（如**有界变差**）使 Riemann-Stieltjes 和收敛--已有的 O(1/n) 数值证据与此一致。

#### E 的依赖结构与作用量泛函

**Q1 形式化**：将 E 写为路径 N(t) 上的泛函 E = E(N(t), N'(t), t)，则：

S = ∫ E(N(t), N'(t), t) · N'(t) dt = ∫ L(N, N', t) dt

其中 L = E · N' 是**拉格朗日量密度**。这是一个标准的**作用量泛函**（action functional）。

对应的 Euler-Lagrange 方程为：

d/dt [∂L/∂N'] - ∂L/∂N = 0

即 d/dt [E + N' · ∂E/∂N'] - N' · ∂E/∂N = 0

**各 claim 中的 E 依赖结构**：
- CHEM：E = Ea（常数，与路径无关）-> L = Ea · N' -> S = Ea · ΔN（平凡情况，E-L 方程恒成立）
- ADAM：E = loss(w(t))（依赖优化轨迹，即路径历史）-> E 是 N(t) 的泛函 -> 非平凡变分问题
- PHASE：E = |T(t) - T_c|/T_c（T(t) 是冷却计划 = 路径参数化）-> E 依赖路径参数化方式

**与理论"最小作用量"原理的连接**：理论断言"系统选择 S 最小的路径"。在作用量泛函框架下，这对应于变分问题 δS = 0。但 Q4 的教训（ISSUE-001）提醒：不能预设极小化者的存在--变分问题的解可能不存在、不唯一、或在物理上不可实现。形式化只是把"系统选择最小 S"从口号变为可分析的数学问题，不保证解存在。

### Q5：量纲问题

- **问题**：九个维度量纲不同，`E` 与 `N` 的乘积在跨维度求和时的意义？
- **候选路线**：与附录E 的九维流形度规合并解决（见下）。在度规完成前，`∫ E dN` 仅对**已统一量纲的单一范式**（如物理范式：J）有严格意义——这也是 E-PARADIGM-001 的发现（统一量纲有意义，但跨范式转换函数非普适）。
- **降维检验**：预设三（F/Φ/N 强耦合可降维）的操作化方案见 [p3-dimension-reduction.md](p3-dimension-reduction.md)。

## 4. 附录E：九维流形度规启动框架（悬赏，待社区）

完整度规推导是独立悬赏项（附录索引"附录E | 度规与测地线推导（启动框架，悬赏完整推导）"）。启动框架：

- **目标**：构造九维流形 `M`（坐标 `(F,S,E,N,R,Φ,K,Ξ,λ)`）上的度规张量 `g_ij`，使结构之间的距离（如马氏距离、余弦相似度）成为 `M` 上的测地线距离的近似。
- **约束**：维度量纲不同 → 度规需含物理单位换算系数（或先标准化到无纲量坐标）；`F/Φ/N` 存在强耦合（1.1 节预设三）——若可互相推导，流形可降维。
- **候选路线**：信息几何（information geometry）路线——把每个结构的九维坐标视为某参数族的分布参数，用 Fisher 信息度量作为 `g_ij`；或数据驱动路线——对大量结构的坐标做 PCA/流形学习，估计内在度规。
- **验收标准**：度规下测地线距离与 2.4 节复制保真度 `Δ_coord` 的一致性；与降维检验（PCA 方差贡献率）的一致性。

### 附录E 度规候选方案（2026-08-02，提出者分析）

#### 候选 1：对角度规（量纲归一化）

最简方案：g_ij = δ_ij / s_i²，其中 s_i 是第 i 维的特征尺度（单位/典型范围）。

- 优点：简单、直接解决量纲问题（Q5）；每个维度按自身尺度归一化。
- 缺点：假设维度间独立（无交叉项），忽略了 F/Φ/N 的强耦合。
- 适用场景：作为 PCA（R1）的预处理标准化方案。

#### 候选 2：Fisher 信息度量（信息几何路线）

将每个结构的九维坐标 θ = (F, S, E, N, R, Φ, K, Ξ, λ) 视为某参数分布族 p(x|θ) 的参数，度规为：

g_ij = E_x [∂_i log p(x|θ) · ∂_j log p(x|θ)]

- 优点：理论上有严格基础（信息几何）；测地线距离有统计含义（KL 散度的局部近似）；自然处理维度间耦合。
- 缺点：需要定义 p(x|θ) -- 不同结构类型（物理/生物/认知）的分布族可能不同；计算复杂。
- 关键挑战：p(x|θ) 的选择不是唯一的，不同选择给出不同度规。需要理论或数据来约束选择。
- 研究入口：对 ADAM 的 loss 曲线（已有解析形式），尝试构造 p(loss | θ) 并计算 Fisher 信息。

#### 候选 3：从 Q1/Q2 作用量泛函导出度规

若 S = ∫ L(N, N', t) dt 是作用量泛函（见 Q1/Q2 形式化），则对应的 Jacobi 度规（Jacobi metric）为：

g_J = 2(E - V(N)) · g_N

其中 E 是总"能量"（常数），V(N) 是"势能"（E 的路径无关部分），g_N 是 N 空间上的度规。

- 优点：直接从理论核心公式导出，不依赖外部概率假设；测地线 = 最小 S 路径。
- 缺点：需要明确 E 的"动能"与"势能"分解（在 ADAM/PHASE 中不显然）；仅适用于固定端点的变分问题。
- 研究入口：在 PHASE claim 中尝试分解 E = |T-T_c|/T_c 的动能/势能部分。

**建议优先级**：候选 1（快速实施，为 PCA 预处理）-> 候选 3（理论最自洽，但需更多分析）-> 候选 2（最一般但最复杂）。三个候选不互斥--可先用候选 1 做数值实验，同时推进候选 3 的理论推导。
