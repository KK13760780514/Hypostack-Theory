# HypoStack 开放验证 · 发布指南（GitHub Issues）

> 目标：将开放决策（DEC-001~008）发布为 GitHub Issues，启动"任务发布 → 预注册 → 提交 → 验证 → 评审 → 证据账本"的贡献循环。
> 前提：`gh` CLI 与 `GH_TOKEN` 在当前环境不可用，本指南为**纯手动发布流程**（浏览器操作）。

## 0. 发布前自检

1. 本地已提交全部修改：证据账本（`evidence-ledger.csv`）、提交 JSON、协议（`protocol-p1-ai.md`）、开放决策（`open-decisions.md`）、已知问题（`known-issues.md`）等。
2. 新增提交均已通过 `python .\open-validation\validate_submission.py <提交.json>` 并已入账。
3. CI（`.github/workflows/ci.yml`）通过。
4. 推送后仓库文档保持一致：**5 个活跃 claim（3 support + 2 challenge）**。

## 1. 手动发布一条 DEC 议题

1. 打开 <https://github.com/KK13760780514/Hypostack-Theory/issues/new>。
2. 选择 **Open decision** 模板（`.github/ISSUE_TEMPLATE/decision.md`）。
3. 粘贴第 3 节中对应的 DEC 草稿。
4. 标题格式：`[Decision] DEC-00X: <短标题>`。
5. 发布后：把 issue 链接回填到 `open-decisions.md` 对应条目的"讨论链接"栏（可选，帮助追踪）。

## 2. 推荐发布顺序

按与当前证据的直接相关性排序，每次发布 1 条，避免刷屏：

| 顺序 | 编号 | 主题 | 理由 |
|------|------|------|------|
| 1 | DEC-008 | ECO 判别力不足 | 最新，阻塞 XD-P2-ECO-001 下一轮设计 |
| 2 | DEC-007 | E-PARADIGM 非普适 | TASK-007 已立项，需社区定方向 |
| 3 | DEC-001 | ADAM 条件数 | 直接关系 support 结果的公平性 |
| 4 | DEC-002 | 无对照计胜 | 与 ADAM 判据相关 |
| 5 | DEC-003 | 种子数 | 统计效力 |
| 6 | DEC-004 | CHEM N=1 | 口径合理性 |
| 7 | DEC-005 | E 最佳定义 | 与 DEC-004 联动 |
| 8 | DEC-006 | 冷却期参数 | 治理参数复议，可最后发 |

### DEC-008：ECO 首次运行的判别力不足如何处理

**决策编号与主题**

DEC-008：ECO 首次运行的判别力不足如何处理（/ EN: How to handle ECO's insufficient discriminative power）

**背景**

`XD-P2-ECO-001`（市场均衡路径选择）：V1（比例佣金，首次运行）12/12 种子 S_A<S_B（p=4.88e-4），但 `ratio_dev = 0.970 > 0.85`——S 差异约 97% 来自佣金率比例因子（构造），行为贡献仅约 9%，且 ZI-C 零智能约束交易者无学习、市场不收敛，速度子预测不可检验（账本行 EV-22c7db69115c4ffc）。V2（学习型交易者，方案 A）：市场收敛问题修复，但速度子预测 5/12（p=0.774），未支持（账本行 EV-b3fd72635845c370）。V3（固定额税，方案 B）：速度子预测 4/12（p=0.388，falsification），高税路径行为几乎不变（账本行 EV-5f2196aa6d3a55cf）。结论：比例佣金与固定税两种操作化均未产出可检验效应。详见 [protocol-p1-ai.md](protocol-p1-ai.md) 第 10 节与 [known-issues.md](known-issues.md) ISSUE-008。

**候选选项**

- A. 交易者加学习规则（EWA/Roth-Erev），使市场真实收敛；以"收敛轮数差异"为主判据、"S 差异"为次判据（已执行 V2，未支持）
- B. E 改用固定额交易税（非比例佣金），消除比例因子主导（已执行 V3，falsification）
- C. S 按单位成交额归一化（S/成交量），检验行为层面效率差异
- D. 接受"交易成本口径在该模型框架下不可检验"的负面结论，收窄或废弃该 claim

**我的立场与理由**

A、B 两案均已产出参考证据且未通过（V2 p=0.774、V3 p=0.388）：问题已从 V1 的"构造性比例因子"转为"效应本身过弱"——0.1%~2% 量级的交易成本不产生可检验的市场行为差异。当前倾向 D（收窄 claim 至"成本归一化下的行为效率"，或接受负面结论）或 C（S/成交量 归一化）；若继续该方向，需显著放大成本量级差或改用真实市场数据。按 ISSUE-006 规则，任何口径修正须重新预注册并默认降级 exploratory（冷却期 14 天）。

**建议的默认值**

D 或 C；社区如认为交易成本效应仍值得检验，请提出成本量级差 ≥10× 的新设计作为对照。

**对现有证据的影响**

- [x] 会改变口径 → 需按 [ISSUE-006](open-validation/known-issues.md) 走降级与冷却期流程
- [ ] 不影响口径，仅治理/流程调整
- [ ] 其他：

**预期共识方式**

- [ ] 简单多数
- [x] ≥2/3 实证评审委员会（当前委员会未组建，以社区讨论为主）
- [ ] 其他
