# TASK-002：压力测试 AI 玩具路径记账口径

> **状态：历史任务，已被 TASK-004 取代。** ISSUE-001 根因分析证明本任务的"人为双路径比较"框架不成立（SGD 不选择路径），修正 A 已落地为 [TASK-004](TASK-004-adam-dynamics.md)。本文件保留作历史记录与口径反面教材。

- Claim: `XD-AI-TOY-001`
- 难度：L2-L3
- 类型：口径挑战 / 多种子稳健性

## 目标

压力测试 [ai_toy_path.py](../reference-implementation/ai_toy_path.py) 的 `E = |Δloss| + compute_weight × learning_rate` 记账口径，判断它是否真的区分“更省力”的训练路径。

## 必做项

1. 固定至少 10 个随机种子。
2. 扫描至少 5 个学习率，覆盖“低步成本高步数”和“高步成本低步数”两类区域。
3. 统一目标损失、最大步数和 `compute_weight`。
4. 报告每条路径的 `S`、步数、最终损失、是否达到目标损失。
5. 明确回答：当前口径下，哪个学习率区域的 `S` 更低？这个结果是否符合玄叠论预期？

## 可选项

- 加入第二种 `E` 定义作为对照，例如只计入 `|Δloss|` 或只计入固定步成本。
- 把任务从一元回归扩展到小分类问题。
- 检查是否存在“步数更少但每步成本更高”反而 `S` 更低的稳定区域。

## 验收标准

- 不允许只报告支持玄叠论的结果。
- 如果口径导致反直觉结果，必须明确写出。
- 提交 JSON 通过 `validate_submission.py`，分类建议使用 `challenge` 或 `exploratory`。

## 交付物

- 预注册 YAML；
- 多种子结果表；
- 提交 JSON；
- 对当前 `E` 口径的改进建议。
