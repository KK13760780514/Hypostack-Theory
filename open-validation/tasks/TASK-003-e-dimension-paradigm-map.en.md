# TASK-003: Propose an E-Dimension Paradigm Conversion Function

- Claim: `XD-E-PARADIGM-001`
- Difficulty: L3
- Type: paradigm conversion / expert task

## Goal

Propose a testable cross-paradigm conversion function for the `E` dimension of HypoStack Theory, covering at least two of the following paradigms: physical energy gradients, biological potential gradients, cognitive difference gradients.

## Required Work

1. Specify the units and operational definitions of the two paradigms.
2. Give the conversion function `E_target = f(E_source)`.
3. Give an error-correction coefficient or loss term.
4. Provide a reproducible example: data, code, and computation process.
5. State under what conditions this conversion function fails.

## Output Requirements

This task does not mandate the use of `submission-schema.json`, but at minimum the following must be submitted:

- the source-paradigm definition of `E`;
- the target-paradigm definition of `E`;
- the conversion function;
- the error model;
- one numerical example;
- reproducible code or computation notebook;
- failure conditions.

## Acceptance Criteria

- The conversion function must be computable, not merely a conceptual analogy.
- It must include an error or loss term.
- At least one counterexample or failure boundary must be given.
- The review focuses on operability, not on whether it supports HypoStack Theory.

## Deliverables

- Paradigm conversion description;
- Reproducible code;
- Numerical example;
- Failure-boundary description.
