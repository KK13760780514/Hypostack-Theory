# TASK-007：按过程类型分类标定 η（E 维度范式转换）

- Claim: `XD-E-PARADIGM-001`
- 难度：L3
- 类型：范式转换 / 数据分析任务
- 前置结论：V2/V3 已证明"无普适跨范式转换函数"，见 [protocol-p1-ai.md](../protocol-p1-ai.md) 第 8 节与 [ISSUE-007](../known-issues.md)。

## 背景

`XD-E-PARADIGM-001` 在 5 个标定点下所有跨范式幂律拟合 R² < 0.64，说明转换函数依赖过程类型（复制类、水解类、转运类、光捕获类等），非普适。统一量纲仍有意义（η 跨度 2.3 个数量级 < 3）。

## 目标

检验"按过程类型分组后，组内转换是否普适"这一新假设：

- 将已有标定点按过程类型分组；
- 在组内重新做跨范式映射与幂律拟合；
- 若组内 R² 显著高于跨组 R²（如 > 0.8），则该假设获支持。

## 必做项

1. 给出过程类型的分类标准（可操作，不依赖主观判断）。
2. 对每个组内的标定点做跨范式映射，报告组内 R²。
3. 与跨组 R² 对比，给出差异是否显著的判断（需预注册统计判据）。
4. 提出可扩展的标定点扩充计划（每个组至少 3 个标定点）。

## 预注册要求

本任务结论将进入证据账本，**必须**预注册：

- `E`、`N`、`S` 的定义沿用 [protocol-p1-ai.md](../protocol-p1-ai.md) 第 8 节；
- 预注册统计判据：组内平均 R² vs 跨组平均 R² 的差异阈值；
- 提交前固定分类标准与标定点集合。

## 验收标准

- 组内 R² 提升是否显著（按预注册判据）；
- 分类标准可复现、不事后调整（口径购物防护，见 ISSUE-006）；
- 必须报告失败条件（若组内 R² 仍 < 0.64，则支持"转换函数既非普适也不按过程类型分组普适"的更严格结论）。

## 交付物

- 过程类型分类标准；
- 组内 vs 跨组 R² 对比表；
- 预注册的统计判据；
- 结果 JSON（按 [submission-schema.json](../submission-schema.json)，classification 按预注册判据填写）。
